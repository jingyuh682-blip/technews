# TechNews Slate Haze 背景配色设计

**日期：** 2026-08-31

## 目标

降低 TechNews 仪表盘整体背景与文字之间过强的明暗冲击，保留冷静的科技编辑气质和信息层级。

## 视觉方向

沿用 calm graphite 的冷蓝灰暗色主题，改为更浅、更雾面的 slate haze：

- 页面底色：`#3E4D55`
- 次级底色：`#495A63`
- 内容面板：`#50616A`
- 面板抬升层：`#5B6D75`
- 主文字：`#DCE5E7`
- 次文字：`#C0CDD0`
- 辅助文字：`#A8B7BB`
- 单一 jade accent：`#7CC2A7`

背景由深黑蓝灰提升为中深 slate，文字同步收敛为柔和的浅灰蓝；面板仍比页面底色略亮，边界和焦点继续依赖低饱和 jade。

## 实现边界

- 仅修改 `public/theme-calm-graphite.css` 及其回归测试。
- 不改动布局、内容、交互、路由或现有未提交业务文件。
- 继续关闭页面噪点，保持单一主题和单一 accent。
- 所有修改、测试、Git 提交和推送均在阿里云服务器执行。

## 验收条件

1. 页面、面板和文字使用上述新 token。
2. 主题测试覆盖新 token，并确认主题链接顺序和噪点关闭逻辑不回退。
3. 完整 Node 测试通过，Git 只包含本次主题文件与对应测试。
