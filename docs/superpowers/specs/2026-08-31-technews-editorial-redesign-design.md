# TechNews 轻杂志新闻门户视觉重构

日期：2026-08-31

## 设计判断

这是一个供科技编辑/研究者高频浏览的新闻仪表盘。现有页面的主要问题是深色背景与金色高对比、中文回退字体不统一，以及四列信息墙造成阅读路径不明确。本次采用轻杂志新闻门户语言：浅灰白页面、墨蓝正文、单一青蓝强调色，强调层级、留白和可扫描性。

## 结构

保留现有数据接口和交互逻辑，只调整 CSS 与静态样式入口：

- 主栏：科技新闻列表跨两行，作为首要阅读入口。
- 右上：热点词云，保留点击释义能力。
- 右侧第二层：科技热点，保留独立滚动。
- 下层：论文热点与读书洞察并列。
- 底部：GitHub 高星与近一周上涨并列。
- 960px 以下自动转为单列，避免固定宽度导致横向滚动。

## 字体与颜色

移除 Google Fonts 外链，使用 Noto Sans SC / Source Han Sans SC / PingFang SC / Microsoft YaHei 的系统回退栈，元信息使用等宽字体。默认主题使用低饱和浅灰白底和墨蓝文字；主题切换器仍可选择冷蓝、深墨、奶油纸、森林绿、莓果紫，并通过现有 localStorage 记忆。

## 验收

远端静态测试检查样式入口、字体栈、网格区域、响应式断点和颜色 token；完整测试需保持原有布局、主题选择器和新视觉验收全部通过。
